# chem501-project-breath
Working code to convert an Arduino into a breathalyzer

# To run this code
 You'll need your own arduino_secrets.h file it should look like this:
    #define SECRET_SSID "[]"        // your network SSID (name)
    #define SECRET_PASS "[]"     // your network password (use for WPA, or use as key for WEP)
    #define SECRET_SERVER "xxxxxxxxxxx.cedalo.cloud"
